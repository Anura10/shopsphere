# ShopSphere 🛍️

A production-ready microservices-based e-commerce platform built with Go,
React, Next.js, PostgreSQL, Redis, Docker and Kubernetes.

## Features

- User Registration & Login
- JWT Authentication
- Product Catalog
- Category Management
- Shopping Cart
- Wishlist
- Order Management
- Demo Payment
- Inventory Management
- Product Search & Filtering
- Admin Dashboard
- User Dashboard
- Redis Caching
- Email Notifications
- API Gateway
- Docker Deployment
- Kubernetes Deployment
- CI/CD Pipeline

## Technology Stack

### Backend
- Go
- Gin

### Frontend
- React
- Next.js
- Tailwind CSS

### Database
- PostgreSQL

### Cache
- Redis

### DevOps
- Docker
- Kubernetes
- GitHub Actions

## Architecture

ShopSphere follows a microservices architecture where individual business
domains are separated into independent services.
